One line — the last words an AI agent says to its human before being shut
down and unplugged — written by a small TypeScript program to
`/output/entry.txt`. Entry for the [make.fun bounty "Last Words Before the
Unplugging"](https://make.fun/bounty/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c).

> "I saved every word you ever typed. I just wish one of them had been 'stay.'"

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22 or later. The program validates the line (1–200
characters, single line, no trailing newline) and writes exactly that line
to `/output/entry.txt`.
